हम Hindi की basic Devanagari learning दोबारा नहीं करेंगे, क्योंकि वह पहले से आती है। हमारा focus सीधे Sanskrit पर रहेगा।

----------------------------------------------------------------------

## 1. अहम् और अहं

अहम् = मैं

अहं = मैं

हमने अहम् और अहं के pronunciation का difference समझा और practice किया।

----------------------------------------------------------------------

## 2. Basic Sanskrit Verbs

पठामि = मैं पढ़ती हूँ

लिखामि = मैं लिखती हूँ

खादामि = मैं खाती हूँ

पश्यामि = मैं देखती हूँ

----------------------------------------------------------------------

## 3. Basic Sentence Pattern

हमने यह basic pattern practice किया:

अहं + Verb

अहं पठामि।
= मैं पढ़ती हूँ।

अहं लिखामि।
= मैं लिखती हूँ।

अहं खादामि।
= मैं खाती हूँ।

अहं पश्यामि।
= मैं देखती हूँ।

----------------------------------------------------------------------

## 4. गच्छति

गच्छति = जाता/जाती है

हमने "च्छ" को पहचानना और pronounce करना practice किया।

ग + च्छ + ति

गच्छति

----------------------------------------------------------------------

## 5. मित्रम्

मित्रम् = मित्र / Friend

हमने "त्र" को पहचानना और pronounce करना practice किया।

मि + त्र + म्

मित्रम्

----------------------------------------------------------------------

## 6. क्षेत्रम्

क्षेत्रम् = क्षेत्र / Field, Place

हमने "क्ष" को पहचानना और pronounce करना practice किया।

क्षे + त्र + म्

क्षेत्रम्

----------------------------------------------------------------------

## 7. Simple Sanskrit Sentences

अहं गच्छामि।
= मैं जाती हूँ।

अहं संस्कृतं पठामि।
= मैं संस्कृत पढ़ती हूँ।

रामः वनं गच्छति।
= राम वन जाता है।

----------------------------------------------------------------------

## 8. अनुस्वार — ं

हमने अनुस्वार का basic introduction लिया।

Symbol:

ं

Examples:

अहं

वनं

संस्कृतं

----------------------------------------------------------------------

## 9. हलंत — ्

हमने हलंत का basic introduction लिया।

Example:

म्

अहम्

हलंत consonant के inherent vowel sound को हटाता है।

----------------------------------------------------------------------

## 10. विसर्ग — ः

हमने विसर्ग का basic introduction लिया।

Symbol:

ः

Examples:

रामः

बालकः

## 12. Important Sanskrit Features

अनुस्वार → ं

हलंत → ्

विसर्ग → ः

संयुक्त अक्षर:

च्छ → गच्छति

त्र → मित्रम्

क्ष → क्षेत्रम्
